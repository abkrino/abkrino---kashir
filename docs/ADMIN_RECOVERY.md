# خطة استعادة كلمة مرور المدير العام (Admin Recovery Protocol)

## 1. الفلسفة الأمنية (Security Rationale)
في أنظمة نقاط البيع المحلية (Local POS) والمحلات التجارية، يُعد وجود أي زر استعادة مباشر أو سؤال أمان ثابت أو كلمة سر عامة (Master Password) ثغرة أمنية جسيمة تمكّن أي شخص أو عامل مؤقت من الاستيلاء على صلاحيات المدير العام والتلاعب بالمخزن وموازين الخزينة وحذف الفواتير.

لذلك، يمنع النظام تماماً أي استعادة محلية بدون تحقق مشفّر (Cryptographically Signed Authorization).

---

## 2. بروتوكول كود الدعم الموقّع (Signed Support Code Protocol)

في الإصدارات القادمة، ستتم استعادة كلمة مرور المدير عبر آلية التحدي والاستجابة (Challenge / Response):

### الخطوة الأولى: توليد كود الطوارئ (Emergency Challenge Code)
عند تعذر دخول المدير بالكامل واختيار "استعادة صلاحيات المدير عبر الدعم الفني":
يقوم جهاز الكاشير محلياً بتوليد رمز تحدٍ مشفر `base64url`:
```json
{
  "v": 1,
  "deviceId": "dev-xxxx-xxxx",
  "orgId": "org-xxxx",
  "branchId": "main",
  "nonce": "random-cryptographic-nonce-128bit",
  "requestedAt": "2026-11-08T12:00:00.000Z",
  "purpose": "admin_password_reset"
}
```

### الخطوة الثانية: التحقق لدى مزود النظام
1. يتواصل مالك المتجر المعتمد مع الدعم الفني ويزودهم بكود التحدي مع إثبات الهوية والاشتراك.
2. تُصدر لوحة تحكم المزود توكناً موقّعاً رقمياً بمفتاح ECDSA P-256 الخاص:
```json
{
  "v": 1,
  "deviceId": "dev-xxxx-xxxx",
  "nonce": "random-cryptographic-nonce-128bit",
  "validUntil": "2026-11-08T13:00:00.000Z", // صالح لمدة ساعة واحدة فقط
  "action": "grant_admin_reset"
}
```

### الخطوة الثالثة: التحقق والفك المحلي
1. يلصق المدير كود الدعم في شاشة الاستعادة بالجهاز.
2. يتحقق الجهاز محلياً دون الحاجة للإنترنت باستخدام المفتاح العام المعتمد في `src/config/licensePublicKey.ts`:
   - مطابقة التوقيع الرقمي (ECDSA P-256 + SHA-256).
   - مطابقة `deviceId` الخاص بالجهاز.
   - مطابقة `nonce` الصادر لمنع هجمات إعادة الإرسال (Replay Attacks).
   - التحقق من عدم انتهاء صلاحية التوكن (`validUntil`).
3. عند نجاح التحقق، يُفتح نموذج فوري لتعيين كلمة مرور جديدة للمدير وتشفيرها بـ PBKDF2-SHA256 (100,000 دورة).
4. يُسجل الحدث فورياً في سجل التدقيق والمراجعة المحلي والسحابي (`AuditTrail`).
