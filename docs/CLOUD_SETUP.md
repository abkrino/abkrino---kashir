# دليل ربط النظام بمشروع Firebase الخاص بك (المزامنة السحابية)

يعتمد التطبيق على ملف الإعدادات المحلي `src/config/firebaseConfig.ts` بدلاً من أي إعدادات افتراضية لبيئة التطوير. عندما تكون أي قيمة في هذا الملف فارغة أو تساوي `'PUT_HERE'`، يعمل النظام **محلياً بالكامل** دون أي اتصال أو أخطاء مزعجة، ويظهر في الواجهة تنبيه **"السحابة غير مُعدّة بعد"**.

---

## الخطوة 1: إنشاء مشروع Firebase وتطبيق الويب
1. افتح [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعاً جديداً (أو اختر مشروعك الحالي).
2. من **Project Settings** (أيقونة الترس) -> قسم **Your apps**، أنشئ تطبيق ويب (**Web App** `</>`).
3. انسخ كائن `firebaseConfig` الظاهر بزر النسخ.

---

## الخطوة 2: لصق الإعدادات في الكود
افتح الملف:
```
src/config/firebaseConfig.ts
```
استبدل قيم `'PUT_HERE'` بالقيم المنسوخة من Firebase Console مع إبقاء `firestoreDatabaseId = '(default)'`:

```ts
export const firebaseConfig: FirebaseWebConfig = {
  apiKey: 'AIzaSy...',
  authDomain: 'your-project.firebaseapp.com',
  projectId: 'your-project',
  storageBucket: 'your-project.firebasestorage.app',
  messagingSenderId: '1234567890',
  appId: '1:1234567890:web:abcdef',
};

export const firestoreDatabaseId = '(default)';
```

> **ملاحظة:** لا حاجة لحذف `firebase-applet-config.json`، فالتطبيق لم يعد يعتمد عليه إطلاقاً.

---

## الخطوة 3: تفعيل المصادقة (Email / Password فقط)
1. من القائمة الجانبية في Firebase Console اختر **Build -> Authentication -> Sign-in method**.
2. فعّل موفّر **Email/Password**.
3. أنشئ حساباً للمنشأة (المحل) من تبويب **Users -> Add user** باستخدام البريد الإلكتروني وكلمة المرور.
4. انسخ قيمة **User UID** الظاهرة بجانب الحساب؛ هذا الـ `UID` هو نفسه **`orgId`** الذي يجب وضعه في ترخيص الجهاز.

> **أمان:** التطبيق يدعم تسجيل الدخول فقط (`signInWithEmailAndPassword`) ولا يتيح إنشاء حسابات جديدة من داخل الواجهة، كما لا يتم تخزين كلمة المرور مطلقاً على الجهاز (تُستخدم جلسة Firebase المحلية تلقائياً).

---

## الخطوة 4: إنشاء قاعدة بيانات Firestore وتطبيق القواعد
1. من القائمة الجانبية اختر **Build -> Firestore Database -> Create database**.
2. اختر قاعدة البيانات الافتراضية **`(default)`** والمنطقة الجغرافية المناسبة (مثل `europe-west3` أو الأقرب لمصر).
3. انشر محتوى ملف `firestore.rules` الموجود في جذر المشروع إلى قواعد الأمان في Firestore Console (تبويب **Rules**).
4. أنشئ المستندات المطلوبة للمحل والفرع في Firestore:
   - المستند: `orgs/{orgId}` (حيث `{orgId}` = `UID` حساب Authentication)
     - `status`: `'active'`
     - `validUntil`: تاريخ مستقبلي (Timestamp)
   - المستند الفرعي: `orgs/{orgId}/branches/{branchId}` (حيث `{branchId}` مطابق لمعرّف الفرع في كود الترخيص)
     - الحقول الأولية للفرع (`name`, `lastSeenAt`, إلخ).

---

## الخطوة 5: تفعيل الترخيص وتسجيل الدخول من التطبيق
1. من التطبيق افتح **الإعدادات -> الترخيص** وفعّل كود الترخيص الذي يحمل نفس `orgId` و`branchId`.
2. افتح **الإعدادات -> المزامنة السحابية**:
   - تأكد من ظهور `orgId` و`branchId` في بطاقة **حالة الترخيص**.
   - أدخل البريد الإلكتروني وكلمة المرور واضغط **"تسجيل دخول المحل للمزامنة"**.
   - اضغط **"اختبار الاتصال"** لإرسال نبضة واحدة فورية والتحقق من نجاح الربط.

---

## سلوك الاتصال عند الإقلاع والعمل الأوفلاين
- **لا يرسل التطبيق أي طلب شبكة إلى Firestore عند التشغيل** إذا لم تكن الإعدادات مكتملة أو لم يكن هناك ترخيص سارٍ وحساب مسجّل.
- يبدأ الاتصال فقط عبر `orgSyncService` عندما تتوافر الشروط الثلاثة معاً: **(إعداد Firebase مكتمل + ترخيص سارٍ + تسجيل دخول المحل يطابق `orgId`)**، أو يدوياً عبر زر **"اختبار الاتصال"**.

---

## دليل رسائل الأخطاء الشائعة
| رمز الخطأ | المعنى والحل المقترح |
|---|---|
| `auth/invalid-credential` | البريد الإلكتروني أو كلمة المرور غير صحيحة. |
| `auth/user-not-found` | لا يوجد حساب بهذا البريد في Firebase Authentication. |
| `auth/too-many-requests` | محاولات دخول متكررة فاشلة؛ انتظر بضع دقائق وأعد المحاولة. |
| `permission-denied` | غالباً بسبب انتهاء/توقف الاشتراك (`status !== 'active'` أو `validUntil` منتهٍ)، أو عدم إنشاء مستند المنشأة/الفرع على السحابة. |
| `not-found` | مستند الفرع `orgs/{orgId}/branches/{branchId}` غير موجود في Firestore. |
| `unavailable` | تعذر الوصول للخادم أو انقطاع الإنترنت؛ يعمل الكاشير محلياً وتُستأنف المزامنة تلقائياً لاحقاً. |
